## 📚 Concepts Learned

### 🔤 Core Java Fundamentals
- Variables, data types, and type casting
- Operators and expressions
- Output with `System.out`

### 🔀 Control Flow
- `if / else if / else` conditionals
- `switch` statements
- `for`, `while`, and `do-while` loops

### 🧱 Object-Oriented Programming (OOP)
- Classes, objects, and constructors
- Encapsulation and access modifiers (`public`, `private`)
- Inheritance and interfaces

### 📦 Collections & Data Structures
- Arrays, `ArrayList`, `HashMap`, `HashSet`
- Iterating with `for-each` and iterators

### 🔡 Strings & Characters
- String manipulation (`substring`, `toUpperCase`, `split`, etc.)
- `StringBuilder` and `char` operations

### ⚙️ Functional Java
- Lambda expressions and method references
- Streams API (`map`, `filter`, `collect`)

### 🚨 Exception Handling
- `try / catch / finally`
- Checked vs. unchecked exceptions

### 🧪 Testing
- Reading JUnit test files
- Test-driven development (TDD) mindset

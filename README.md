## 📚 Concepts Learned

### 🔤 Core Java Fundamentals
- Variables, data types, and type casting
- Operators and expressions
- Input/output with `System.out`

### 🔀 Control Flow
- `if / else if / else` conditionals
- `switch` statements
- `for`, `while`, and `do-while` loops

### 🧱 Object-Oriented Programming (OOP)
- Classes and objects
- Constructors and instance variables
- Methods and return types
- Encapsulation and access modifiers (`public`, `private`)
- Inheritance and `extends`
- Interfaces and `implements`
- Abstract classes

### 📦 Data Structures & Collections
- Arrays and multi-dimensional arrays
- `ArrayList` and `LinkedList`
- `HashMap` and `HashSet`
- Iterating with `for-each` and iterators

### 🔡 Strings & Characters
- String manipulation (`substring`, `toUpperCase`, `split`, etc.)
- `StringBuilder` for efficient string building
- `char` operations and `Character` utility class

### ⚙️ Functional & Modern Java
- Lambda expressions
- Streams API (`map`, `filter`, `reduce`, `collect`)
- Optional
- Method references

### 🚨 Exception Handling
- `try / catch / finally`
- Checked vs. unchecked exceptions
- Custom exceptions

### 🧪 Testing
- Reading and understanding JUnit tests
- Test-driven development (TDD) mindset
- Writing assertions

## 🚀 How to Run

Make sure you have **Java 17+** and **Gradle** installed.

```bash
# Clone the repository
git clone https://github.com/supershenelle/exercism-java.git
cd exercism-java

# Navigate to an exercise
cd exercises/hello-world

# Run the tests
./gradlew test
```
